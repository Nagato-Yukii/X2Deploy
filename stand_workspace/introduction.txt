此工作空间完成x2的默认站立控制，可作为baseline进行测试

stand_workspace/
├── src/
│   └── x2_stand_controller/         # 初始位姿控制包
│       ├── CMakeLists.txt           # 编译配置 (需链接 rclcpp 和 aimdk_msgs)
│       ├── package.xml              # 包信息声明
│       ├── include/
│       │   └── x2_stand_controller/
│       │       └── stand_node.hpp   # 节点头文件，声明发布者和定时器
│       ├── src/
│       │   └── stand_node.cpp       # 核心逻辑：读取 YAML 参数并以 500Hz 发布指令
│       ├── config/
│       │   └── initial_pose.yaml    # ★ 核心资产：存放 SOP 3.3 的关节参数
│       └── launch/
│           └── stand.launch.py      # 启动文件，负责加载 YAML 参数并启动节点
└introduction.txt # 介绍该工作空间

个人本机测试
    终端1:
        source ~/Desktop/lx2501_3-v0.8.2.4/install/setup.bash
        cd Desktop/X2Deploy/Stand_workspace
        colcon build --symlink-install

        打印结果为:
            Starting >>> x2_stand_controller
            Finished <<< x2_stand_controller [3.12s]
            Summary: 1 package finished [3.33s]
        source install/setup.bash
        ros2 launch x2_stand_controller stand.launch.py
        终端打印出El Psy Kongroo. Stand Node Initialized properly.

    终端2:
        监听节点:(本机与X2通过网线相连)
        ros2 topic hz /aima/hal/joint/leg/command

        打印结果显示:average_rate约为480，相邻两次指令的最大时间间隔约为0.05s，不能运行rl的locomotion
