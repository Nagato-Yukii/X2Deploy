mnidirectional walking全向行走部署使用的模型来自
github仓库:X2ULTRA_RL_ISAACLAB
链接:https://github.com/Nagato-Yukii/X2ULTRA_RL_ISAACLAB

模型描述:
在训练仓库中，训练任务是Zhiyuan-X2Ultra-31dof-Velocity

决策频率 50Hz (decimation = 10)
obs每帧45维：
   Term               维度      量纲与缩放              说明
base_ang_vel           3       rad/s*0.2       base frame角速度Imu
projected_gravity      3       单位向量[-1,1]    body frame 重力方向
velocity_commands      3     [m/s,m/s,rad/s]    [vx,vy,wz]
joint_pos_rel          12      rad无缩放        关节当前角-默认角
joint_vel_rel          12      rad/s * 0.05     关节角速度
last_action            12      网络原始输出       上一步Actor输出
history_length = 5,总输入225维
IsaacLab按照term分组堆叠，每个term有独立历史buffer
顺序是oldest-->newest
前几帧冷启动，没有得到的全用第0步观测值

策略输出顺序

交替顺序，在obs中关节也是如此顺序
  L_hip_pitch, R_hip_pitch,
  L_hip_roll,  R_hip_roll,                                                      
  L_hip_yaw,   R_hip_yaw,
  L_knee,      R_knee,                                                          
  L_ankle_pitch, R_ankle_pitch,
  L_ankle_roll,  R_ankle_roll

关节位置控制
target_pos = action × 0.15 + default_pos(rad) action_scale = 0.15，use_default_offset = True

速度指令范围(课程)
vx (-0.1,0.1)m/s-->(-0.5,1.0)m/s
vy (-0.1,0.1)m/s-->(-0.3,0.3)m/s
wz (-0.1,0.1)rad/s-->(-0.2,0.2)rad/s

本机测试:
  将CMakeLists关于ONNX Runtime的路径改成自己电脑的路径后进行编译,编译成功后

  测试通信和上位机心跳机制
  四个终端运行
    cd Desktop/X2Deploy/omnidirectional_walking_workspace
    source ~/Desktop/lx2501_3-v0.8.2.4/install/setup.bash
  终端1:
    python3 test_publisher.py  # 这个脚本往state节点发送模拟状态给主控rl_node订阅，并订阅主控输出的command
    此时打印Test publisher started
  终端2:
    python3 life_support.py
    此时打印Life Support Active. Keeping the robot conscious
  终端3:
    source install/setup.bash
    ros2 launch x2_rl_controller locomotion.launch.py
    此时打印El Psy Kongroo. RL Locomotion Node Activated.且终端1打印 Received command for 12 joints
  终端4:
    ros2 topic hz /aima/hal/joint/leg/command
    此时因为都是在本机，average rate≈500,max<0.004s
    且ros2 topic echo /aima/hal/joint/leg/command不为0 说明通信正常
  此时中断终端2,上位机的消息不被接收,终端3打印!!! COMM LOSS DETECTED !!! No heartbeat for 0.101495 s
  ros2 topic echo /aima/hal/joint/leg/command 均为0
